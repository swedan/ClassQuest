# HCT ClassQuest 2.0 — Universal AI Prompt Builder

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or another modern browser.
3. Select **AI Prompt Builder**, configure the number and types of questions, difficulty and course.
4. Click **Generate My Prompt** and then **Copy Prompt** (or download it as `.txt`).
5. Open your preferred AI tool, paste the prompt, and attach your lecture PPT/PDF **there**.
6. Download the generated `.xlsx` question bank and load it into ClassQuest using **Load Question Bank**.

No API key, backend, account or AI subscription is required **by ClassQuest**. The AI tool you choose may have its own requirements, limits or fees.

## Existing features
The original Excel/CSV upload, question selection, automatic countdown, answer reveal, MCQ formatting and statistics remain in the application.

## Notes
- ClassQuest does not upload or process PowerPoint files; the teacher supplies slides directly to their chosen AI tool.
- The teacher must check the generated questions for correctness and follow institutional policies before uploading confidential teaching materials to an AI provider.
- Excel and CSV import rely on the SheetJS script loaded from a CDN, so an internet connection may be required.
